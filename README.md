# SQL Problem Solving - University of California, Davis

Assignment for [Data Wrangling, Analysis and AB Testing with SQL](https://www.coursera.org/learn/data-wrangling-analysis-abtesting) was run on [Mode Analytics](https://mode.com). The final outputs are available [here](https://app.mode.com/sqlproblemsolvingg/reports/14637060fea7/runs/ebda442e117c). Course completion certification is available [here](https://coursera.org/share/ecdd5251b43c179beab22b3fa03020e3).

Overall goal was to analyse results of A/B testing for a hypothetical online shopping company. Metrics calculated were:

* Orders in the 30-day window after test assignment
* Page views in the 30-day window after test assignment
